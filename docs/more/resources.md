# Дополнительные ресурсы

Здесь собраны полезные ресурсы, связанные с фреймворком Joke: стартовые шаблоны, дополнительные библиотеки, примеры приложений и обучающие видеоматериалы.

## Скелетоны

[voral/joke-minimal](https://github.com/joke-php/minimal) Минимальный стартовый шаблон для проектов на основе фреймворка 

## Библиотеки

- [joke-php/templator](https://github.com/joke-php/templator) Шаблонизатор.
- [joke-php/db-sql](https://github.com/joke-php/db-sql) Библиотека предоставляет базовые возможности взаимодействия с реляционными базами данных, необходимые интерфейсы, а также реализацию на базе PDO.
- [joke-php/avatar](https://github.com/joke-php/avatar) Библиотека для генерации квадратных PNG-аватаров на основе никнейма для фреймворка.

## Примеры использования

- [Приложение список задач](https://github.com/joke-php/example-todo) простое веб-приложение списка задач созданное с использованием фреймворка.
