# Отправка электронной почты

Фреймворк Joke предоставляет встроенную систему для отправки электронных писем. Она спроектирована так, чтобы быть
простой в использовании, но при этом гибкой и безопасной. Система поддерживает кодирование UTF-8 (включая кириллицу),
автоматическое формирование MIME-заголовков и защиту от инъекций.

## Быстрый старт

Для отправки письма вам понадобятся три основных компонента: адрес отправителя/получателя (`Address`), само письмо (
`Email`) и транспорт (`TransportInterface`).

```php
use Vasoft\Joke\Mail\Address;
use Vasoft\Joke\Mail\Email;
use Vasoft\Joke\Contract\Mail\TransportInterface;

// 1. Создаем адреса
$from = new Address('noreply@example.com', 'Joke Framework');
$to = [new Address('user@example.com', 'Василий')];

// 2. Создаем письмо
$email = new Email(
    from: $from,
    to: $to,
    subject: 'Добро пожаловать!',
    text: 'Это текстовая версия письма.',
    html: '<h1>Привет!</h1><p>Это HTML-версия.</p>'
);

// 3. Получаем транспорт из контейнера и отправляем
$transport = $container->get(TransportInterface::class);
$transport->send($email);
```

## Основные компоненты

### Адреса (`Address`)

Класс `Address` представляет собой неизменяемый объект (Value Object). Он хранит email и опциональное имя.

* **Безопасность:** Имена автоматически экранируются для предотвращения ошибок в заголовках.
* **Гибкость:** Поддерживает как простые адреса (`user@mail.ru`), так и полные (`"User Name" <user@mail.ru>`).

### Письмо (`Email`)

Объект `Email` содержит всю информацию о сообщении.

* **Тела письма:** Вы можете передать как plain-text (`$text`), так и HTML (`$html`) версию. Фреймворк сам определит тип
  контента. 
* **Заголовки:** Вы можете передавать дополнительные заголовки через конструктор или работать с ними через свойство
  `$email->headers`.

### Транспорт (`TransportInterface`)

По умолчанию фреймворк использует `NativeTransport`, который отправляет письма через стандартную функцию PHP `mail()`.

> **Важно:** Для корректной работы `NativeTransport` на сервере должен быть настроен локальный MTA (например, Postfix
> или Sendmail).

## Работа с заголовками

Фреймворк автоматически добавляет необходимые MIME-заголовки (`MIME-Version`, `Content-Type`,
`Content-Transfer-Encoding`). Вы можете добавить свои заголовки:

```php
$email->headers->set('X-Custom-Header', 'MyValue');
$email->headers->set('Reply-To', new Address('support@example.com'));
```

Все заголовки проходят проверку на безопасность (sanitization) перед отправкой. Пустые заголовки удаляются
автоматически.

## Поддержка кириллицы и длинных тем

Вам не нужно беспокоиться о кодировании.

* Если тема письма или имя получателя содержат кириллицу, фреймворк автоматически закодирует их в формат MIME (Base64).
* Длинные строки автоматически разбиваются на части согласно стандартам RFC.

```php
// Даже такое длинное русское название будет обработано корректно
$email = new Email(
    from: $from,
    to: [new Address('client@mail.ru', 'Александр Сергеевич Пушкин')],
    subject: 'Очень длинная тема письма с кириллицей, которая требует специального кодирования'
);
```

## Конфигурация

Вы можете изменить используемый транспорт в конфигурации приложения (`ApplicationConfig`):

```php
// config/app.php

use App\MyTransport;
use Vasoft\Joke\Application\ApplicationConfig;

return new ApplicationConfig()
    ->setMailTransportClass(MyTransport::class);

```

Иные транспорты планируется реализовать отдельными модулями.
